Connect Your Demo Account

This version uses Deriv's newer REST API for account authorization and the newer public WebSocket for live market ticks. Your token is sent only to Deriv over HTTPS, is not saved in browser storage, and is cleared after successful authorization. The account-list endpoint requires the API permission specified by Deriv (currently trade scope); this app itself never sends trade orders. Use a demo account for testing and never share your token.
